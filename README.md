# comp-simulation

Repositorio de laboratorios académicos de la materia **Simulación Computacional**
(Universidad de los Llanos).

Aquí se suben las prácticas del curso: notebooks, datos de entrada, gráficas e
informes de cada laboratorio. Cada práctica vive en su propia carpeta.

## Contenido

| Carpeta | Práctica |
|---|---|
| `lab1_simulacion_ad_hoc/` | Práctica No. 1 — Simulación ad hoc: intervalos de confianza sobre 10 corridas del ejemplo de la fila del banco |

## Estructura de cada laboratorio

Cada carpeta suele incluir:

- El notebook (`.ipynb`) con el desarrollo.
- Los datos de entrada (`.xlsx`, `.csv`).
- Las gráficas generadas.
- El informe final en PDF.

## Ejecución

Los notebooks se pueden abrir en Jupyter local o en Google Colab. Dependencias
habituales:

```bash
pip install numpy pandas scipy matplotlib openpyxl
```

Si se ejecuta localmente, mantén los archivos de datos en la misma carpeta que
el notebook.
